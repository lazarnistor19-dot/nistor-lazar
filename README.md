# StiriMoldova (demo)

Acesta este un prototip simplu de portal de stiri pentru Moldova.

## Cum il deschizi

### 1) Deschidere directa
Deschide fisierul `index.html` in browser (double-click).

### 2) Server local (recomandat)
Din terminal, in radacina proiectului:

```bash
python -m http.server 8000
```

Apoi deschide:

```
http://localhost:8000/index.html
```

## Structura
- `index.html` – structura paginii
- `styles.css` – stilizarea paginii
